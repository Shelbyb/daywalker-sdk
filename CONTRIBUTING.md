## 2. Review and Acceptance Policy

* **Sole Discretion:** Shelby Tech LLC reserves the absolute right to accept, reject, modify, or close any pull request, issue, or proposed modification without liability or obligation.
* **Core SDK & Gating Integrity:** Submissions that attempt to weaken, mock, bypass, circumvent, or remove integrations with proprietary components, rate-limiting handlers, or licensing validation modules will be closed immediately.
* **Pull Request Workflow:**
    1. Open an issue first to discuss substantial architecture, schema, or functional changes.
    2. Ensure all tests and linting suites pass cleanly locally.
    3. Include a concise description of the problem solved, implementation details, and test coverage in the pull request description.
